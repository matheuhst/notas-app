# Notas App

Aplicação simples para salvar, editar e excluir notas usando Node.js + Express e SQLite.

Como usar:

1. Instale dependências:

```
cd "c:/Users/Matheus/Documents/Banco de dados"
npm install
```

2. Inicie o servidor:

```
npm start
```

3. Abra o navegador em `http://localhost:3000`.

A interface permite digitar uma nota grande, salvar, editar e excluir. As notas são agrupadas por data e exibem hora de criação/edição.
